# BracketLab CS2

Офлайн-конструктор турниров на 2–64 команды. Нативные приложения для Windows x64 и Android обмениваются проектами в JSON.

## Установка

Готовые сборки доступны в [релизе v0.2.0](https://github.com/gearbarium/BracketLab-CS2/releases/tag/v0.2.0).

Обновление Windows 0.2.0, менеджер турниров и перенос существующей базы описаны в [отчёте об обновлении](docs/update-0.2.0.md).

- **Windows 10/11 x64.** Запустите `dist/BracketLab-CS2-0.2.0.exe`. Обычная сборка хранит турниры в `%LOCALAPPDATA%\BracketLab`. Для переносимого режима распакуйте ZIP в доступный для записи каталог и оставьте файл `BracketLab.portable` рядом с EXE.
- **Android 8.0 и новее.** Откройте `dist/BracketLab-CS2-Android-0.2.0.apk` на устройстве и подтвердите установку из выбранного источника. Через ADB используйте `adb install -r dist/BracketLab-CS2-Android-0.2.0.apk`. APK подписан тестовым ключом для локальной установки. Миграция и сравнение платформ описаны в [отчёте Android 0.2.0](docs/android-0.2.0.md).

## Первый турнир

1. Откройте «Команды». Укажите название турнира и введите команды по одной на строку. После сохранения можно добавить логотипы, описание и игроков.
2. Нажмите «Новый этап». Выберите формат, BO и число групп. Чтобы ограничить перемешивание, задайте размер корзины и закрепите нужные позиции. Проверьте порядок в предпросмотре.
3. Откройте карточку матча. Введите счёт серии или счёт по картам. Следующие участники появятся сразу после сохранения результата.
4. Для плей-офф после групп создайте новый этап и выберите «Квалификация из этапов». Укажите завершённые группы и число проходящих из каждой.
5. Экспортируйте турнир, этап или раунд в PNG. Для переноса на другую платформу используйте «Проект → Экспорт JSON» и «Импорт JSON».

Поддерживаются Single Elimination с матчем за третье место, Double Elimination с опциональным повторным гранд-финалом, Round Robin в один или два круга, Swiss с ручной перестановкой текущих пар и GSL на четыре команды. Группы отображаются как отдельные этапы. Квалификация связывает их с плей-офф.

На Windows перетаскивайте поле и меняйте масштаб колёсиком. На Android перетаскивайте одним пальцем и масштабируйте двумя. Кнопка «Вписать» возвращает полную сетку в область просмотра. В меню «Проект» доступны история и уменьшение движения.

## Сборка из исходников

### Windows

Нужны стабильный Rust и компилятор C для встроенного SQLite. Подойдут Windows MSVC с инструментами сборки Visual Studio или Windows GNU с MinGW-w64. Проверенная сборка использовала Rust 1.100.0 для `x86_64-pc-windows-gnu` и WinLibs GCC 15.2.0 UCRT.

```powershell
cargo test --locked --release
cargo build --locked --release
.\target\release\bracketlab.exe --preview
.\target\release\bracketlab.exe --fixtures dist/scenes
```

### Android

Нужны JDK 17 и Android SDK 35. Соберите через Gradle Wrapper из каталога `android`.

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug assembleRelease
```

Для получения подписанного Release передайте `BRACKETLAB_KEYSTORE`, `BRACKETLAB_STORE_PASSWORD`, `BRACKETLAB_KEY_ALIAS` и `BRACKETLAB_KEY_PASSWORD` через переменные окружения. Без них Gradle собирает `app-release-unsigned.apk`. Файлы APK находятся в `android/app/build/outputs/apk`.
