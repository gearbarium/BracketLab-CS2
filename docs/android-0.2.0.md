# BracketLab CS2 0.2.0 · Android

| Возможность Windows | Реализация Android |
|---|---|
| Карты в BO1/BO3/BO5 | Карточки переменной высоты. Сыгранные карты видны при приближении. Частичная серия сохраняется без продвижения победителя. |
| Экспорт последующих раундов | Начинается с раунда выбранного матча. Переходы в соседние ветви вычисляются по зависимостям. Диалог показывает список включённых раундов. |
| Прокрутка и масштабирование | На холсте работают панорамирование одним пальцем и масштабирование двумя. Прокрутка панелей и редакторов обрабатывается отдельно. |
| Состав команды | Редактирование и удаление по UUID. У старых записей UUID появляются при первом сохранении состава в новом редакторе. |
| Окна и панели | Адаптивные диалоги Material 3 с прокруткой содержимого и отдельной строкой действий. Компактная шапка при малой высоте. |
| Удаление этапа | Подтверждение показывает число матчей и результатов. Зависимость блокирует удаление. Индексы остальных связей пересчитываются. |
| Каталог турниров | Создание, открытие, переименование, дублирование и удаление. Room хранит выбранный турнир и отдельную историю каждого проекта. |
| Призовые места | Выдвижная панель на телефоне и боковая панель на широком экране. Бронза Single Elimination определяется по матчу за третье место. Swiss завершается явно. Для PNG всего турнира есть опция пьедестала. |
| Логотип | Предпросмотр с сохранением пропорций, замена и удаление. Холст и призовые места обновляются после сохранения. |

## Установка и данные

Установите `dist/BracketLab-CS2-Android-0.2.0.apk` поверх версии 0.1.0, если она подписана тем же ключом. Сборка из комплекта подписана прежним локальным тестовым ключом.

Миграция Room сохраняет старые ревизии и журнал в первом турнире каталога. Перед изменением схемы активный проект сохраняется в приватный файл приложения `bracketlab-v2-backup.json`. Импорт JSON Windows создаёт отдельную запись каталога. Экспорт JSON сохраняет выбранный проект. Файлы SQLite у платформ имеют разные схемы.

PNG использует масштаб 1×/2×, поля и прозрачность. Android ограничивает растровый буфер 16 млн пикселей. Если схема превышает лимит, выберите меньший масштаб или экспортируйте отдельный участок.

## Проверка

- Прошли 12 тестов Kotlin и 18 тестов Rust. Проверены общий seed жеребьёвки, промежуточный счёт, призовые места, зависимости этапов и выбор ветвей Double Elimination для PNG.
- На эмуляторе API 35 установлена версия 0.2.0 поверх 0.1.0. Турнир с четырьмя командами и результатом финала сохранился. Создан второй пустой турнир. После перезапуска выполнен возврат к первому турниру через каталог.
- Импортирована сцена Windows с результатами карт, составом и логотипом. После удаления среднего игрока соседние SteamID сохранились. Экспортированный Android JSON прошёл проверку Windows EXE.
- Из полуфинала M05 получен PNG с обоими полуфиналами и финалом. Четвертьфиналы исключены. Удаление импортированного этапа с подтверждением и восстановление через Undo проверены в интерфейсе.
- Проверены [портретный холст с картами](../dist/android-0.2.0-portrait.png), прокрутка редактора, панорамирование одним пальцем и [боковая панель на планшетном размере](../dist/android-0.2.0-landscape.png).
- На эмуляторе проверены замена логотипа, сохранение, удаление и Undo. В компактной альбомной ориентации [поле названия остаётся над клавиатурой](../dist/android-0.2.0-keyboard-landscape.png). После закрытия клавиатуры действия редактора снова видны. [Портретная панель](../dist/android-0.2.0-podium-final.png) показывает все три места и кнопку закрытия.

Двухпальцевый жест и работа на физических устройствах остаются без ручной проверки. Ветвление Double Elimination проверено автоматическими тестами. Ручной экспорт PNG выполнен на Single Elimination.
