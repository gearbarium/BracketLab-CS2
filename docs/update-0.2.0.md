# BracketLab CS2 0.2.0 · Windows

## Что изменилось

- **Карточки матчей.** Сыгранные карты отображаются под счётом серии. Неполная серия с заполненными картами сохраняется со статусом «Идёт» и не продвигает победителя. Технический результат помечается `TECH`. Если есть только общий результат BO3 или BO5, карточка сообщает, что детали карт не указаны.
- **PNG.** Режим «Раунд выбранного матча и все последующие» начинает с полного раунда выбранной ветви. Он добавляет оставшиеся раунды этой ветви. Когда один из включённых матчей ведёт в другую ветвь, экспорт включает целевой раунд той ветви и последующие. В Double Elimination из верхней сетки можно попасть в нижнюю и гранд-финал. Из нижней сетки можно попасть в гранд-финал. Для всего турнира можно добавить призовые места.
- **Прокрутка и окна.** Колесо работает в верхней области под указателем. Редактор матча, команды, этап и экспорт получили более широкие поля и прокрутку. В карточках результат карт плавно появляется при приближении.
- **Команды.** В редакторе есть квадратный предпросмотр логотипа с сохранением пропорций. У каждого игрока есть карточка и удаление по UUID. Изменения применяются после «Сохранить команды». После сохранения их можно отменить через Undo.
- **Этапы.** «Удалить этап» доступно в контекстном меню. Диалог показывает количество матчей и результатов. Если следующий этап зависит от удаляемого, сначала нужно удалить зависимый этап. Ссылки на оставшиеся этапы обновляются.
- **Менеджер турниров.** В меню «Проект» можно создать, открыть, переименовать, дублировать и удалить турнир. Импорт JSON создаёт отдельный турнир. История Undo и Redo ведётся отдельно для каждого турнира.
- **Призовые места.** Панель справа можно скрыть кнопкой с кубком. В Single Elimination третье место определяется по матчу за бронзу. При отсутствии такого матча бронза остаётся неопределённой. Swiss завершите кнопкой «Завершить Swiss» после последнего запланированного тура. Для этапов с таблицей действует настроенный критерий, а при полном равенстве применяется порядок посева.

## Обновление

Закройте прежнюю версию и запустите `BracketLab-CS2-0.2.0.exe`. Обычная сборка использует прежнюю базу в `%LOCALAPPDATA%\BracketLab`. При обновлении переносимой установки оставьте `BracketLab.portable` и каталог `data` рядом с новым EXE.

При переходе на схему 3 создаётся согласованная резервная копия `bracketlab.v2-<UUID>.backup.sqlite3` в каталоге базы. Текущий проект и его прежние ревизии остаются доступны. Прежний Windows EXE рассчитан на предыдущую схему базы.

## Код

- `migrations/003.sql`, `src/storage.rs` — каталог, выбор проекта, привязка ревизий и журнала, резервная копия.
- `src/tournament.rs` — UUID игроков, удаление этапов, частичные серии, призовые места.
- `src/main.rs` — менеджер, панели, предпросмотр, маршрутизация прокрутки.
- `src/scene.rs`, `src/fixtures.rs` — размеры карточек, линии между ветвями, состав экспорта и тестовые сцены.
- `tests/update.rs` — миграция, изоляция турниров, история, удаление и призовые места.
- `android/app/src/main/java/com/bracketlab` — совместимость JSON и обработка частичных серий. Новый интерфейс относится к Windows.

## Границы проверки

Автоматические тесты проверяют миграцию с копией SQLite, повторное открытие, изоляцию турниров, удаление, форматы BO1/BO3/BO5, геометрию, области прокрутки и PNG. Нативные снимки показывают внешний вид на выбранных масштабах. Сценарии с реальной базой пользователя и измерения производительности остаются за пределами этой проверки.
